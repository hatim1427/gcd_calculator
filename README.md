# GCD Calculator

## Overview

A simple Python program that calculates the Greatest Common Divisor (GCD) of two numbers.

This project demonstrates basic algorithmic problem solving and Python programming.

## Features

- Takes two numbers as input
- Calculates their Greatest Common Divisor
- Displays the result to the user

## Technologies

- Python
